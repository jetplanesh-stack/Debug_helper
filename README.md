# 🎓 웹앱 디버거 - 학생용 & 전문가용

웹사이트를 자동으로 테스트하고 AI가 분석해주는 도구입니다.

## 📦 설치

### 1. 필수 패키지 설치

```bash
pip install streamlit anthropic python-dotenv requests beautifulsoup4
```

### 2. 환경 설정

`.env` 파일을 만들고 다음을 추가하세요:

```
ANTHROPIC_API_KEY=your_api_key_here
```

> **API 키 얻기**: https://console.anthropic.com/

## 🚀 실행 방법

### 학생용 버전 (추천)
초보자나 학습용으로 추천됩니다. 간단한 UI와 명확한 설명이 포함되어 있습니다.

```bash
streamlit run app_student.py
```

**특징:**
- ✅ 쉬운 인터페이스
- ✅ 명확한 오류 메시지
- ✅ 학습 팁 포함
- ✅ 단계별 테스트 가이드
- ✅ 모든 오류 처리 완료

### 전문가용 버전
상세한 분석과 고급 기능이 필요한 경우 추천됩니다.

```bash
streamlit run app_professional.py
```

**특징:**
- 🔧 보안 헤더 검사
- 📊 성능 분석 (GZIP, 로딩 시간)
- 🔗 전체 링크 검사 옵션
- 📄 접근성 검사 (alt text, H1 태그)
- 🎯 전문가 수준의 보고서

## 📋 사용 방법

### 1단계: 웹사이트 URL 입력
```
예시: google.com 또는 https://example.com
```

### 2단계: 테스트 시작
"🚀 테스트 시작" 버튼을 클릭하면 자동으로 테스트가 진행됩니다.

### 3단계: 결과 확인
- **HTTP 상태코드**: 웹사이트가 정상인지 확인
- **로딩시간**: 웹사이트가 얼마나 빠른지 확인
- **페이지 구조**: 링크, 이미지, 폼 등의 요소 개수
- **AI 분석**: Claude AI가 제시하는 개선 사항

### 4단계: 보고서 다운로드
생성된 보고서를 다운로드하여 저장할 수 있습니다.

## 🎓 학생용 버전 - 학습 포인트

### HTTP 상태코드
- **200**: 정상 ✅
- **404**: 페이지를 찾을 수 없음 ❌
- **500**: 서버 오류 ❌
- **403**: 접근 권한 없음 ❌

### 로딩 시간 기준
- **< 1초**: 매우 빠름 🚀
- **1-3초**: 적당함 👍
- **> 3초**: 느림 ⚠️

### 웹사이트 분석
- **링크**: 페이지에서 다른 페이지로 이동하는 버튼
- **이미지**: 사진이나 그래픽 요소
- **폼**: 사용자 입력을 받는 양식 (로그인, 검색 등)
- **버튼**: 클릭할 수 있는 요소
- **스크립트**: 웹사이트의 상호작용을 처리하는 코드

## 🔧 전문가용 버전 - 고급 기능

### 분석 모드

#### 빠른 스캔 (Quick Scan)
- 기본 정보만 확인
- 빠른 결과 제공

#### 완전 분석 (Full Analysis)
- 모든 링크 검사
- 더 자세한 분석
- 시간이 더 오래 걸림

### 보안 헤더 검사
- **X-Frame-Options**: 클릭재킹 공격 방어
- **X-Content-Type-Options**: MIME 타입 스니핑 방지
- **Strict-Transport-Security (HSTS)**: HTTPS 강제

### 성능 분석
- **로딩 시간 (ms)**: 밀리초 단위 로딩 시간
- **GZIP 압축**: 데이터 압축 여부
- **콘텐츠 크기**: 페이지 크기

### 접근성 검사
- H1 태그 검사 (페이지당 정확히 1개여야 함)
- 이미지 alt 텍스트 검사

## 🆘 문제 해결

### API 키 오류
```
❌ API 키가 설정되지 않았습니다.
```
**해결**: `.env` 파일에 `ANTHROPIC_API_KEY`를 추가하세요.

### 연결 실패
```
❌ 연결 실패: 인터넷 연결을 확인해주세요
```
**해결**: 
- 인터넷 연결 확인
- 방화벽/프록시 설정 확인

### 타임아웃
```
❌ 요청 타임아웃: 웹사이트 응답이 너무 느립니다
```
**해결**: 
- 웹사이트가 정상인지 확인
- 나중에 다시 시도

### BeautifulSoup 설치 오류
```bash
pip install beautifulsoup4
```
